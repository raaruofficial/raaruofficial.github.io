Read this before paying

A split payment is one public transaction on Solana. It permanently shows every destination address, every amount, and the percentage each destination receives. Anyone who knows any one of those addresses can find the whole split and join it up, forever. This page shortens the addresses it displays, but that hiding is only on this page — it does not hide them on-chain.

Even the percentages on their own reveal a detailed picture of the owner's money, so sharing this link is a deliberate act.

About TITHE — Self-Sweep Splitter

TITHE is a self-sweep splitter for Solana: set a percentage split across your own wallets, and every payment divides in one transaction. No token, no church, no custody — TITHE never holds your funds.

TITHE has no token. The token using the mint BsdNL85AKVyK46sGekLbSysbA3rYBLuFifJwKbDXpump is unrelated to TITHE.

How to read this tool: a split rule is friction, and a rule set in advance. The owner keeps full control of every destination and can move funds back at any time.

Editing a split makes a new link. Links already shared keep paying the old split.

This page runs entirely on your device. The split rule travels inside the link itself, after the #, so it is never sent to a server when the page loads. The page holds no funds and takes no cut of any payment.
